# 用户登录、CDK 归属与管理后台

## 用户流程

1. 打开工作台先进入注册/登录页，未登录时不会加载任务、卡密和提链操作。
2. 注册成功或登录成功后，API 返回短期 Bearer token。Vue 前端把 token 保存到当前浏览器会话，刷新页面会自动恢复登录。
3. 管理员停用用户后，该用户的 token 会立即失效，无法继续提交或查询任务。

用户接口：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/v1/auth/register` | 注册用户名、密码和显示名称 |
| POST | `/api/v1/auth/login` | 登录并返回 token |
| GET | `/api/v1/auth/me` | 返回当前用户和权限配置 |

除注册、登录外，用户接口使用 `Authorization: Bearer <token>`。

## CDK 归属规则

- 用户首次成功校验一个未绑定 CDK 时，CDK 会在 PostgreSQL 中写入 `owner_user_id` 和绑定时间。
- 已绑定其他用户的 CDK 会返回 403，不能校验、提链或作为融合来源。
- 已绑定当前用户的 CDK 可以继续校验、提链和融合。
- 融合时，所有来源 CDK 必须是未绑定或属于当前用户；来源卡会标记为 `fused`，新卡绑定当前用户。
- 管理员卡密库存显示完整 CDK、绑定用户 ID、绑定时间、备注和额度，方便处理归属问题。

## 管理后台

管理员入口仍使用 `ADMIN_API_TOKEN`，数据全部来自 PostgreSQL，Redis 和 Kafka 的连接状态在仪表盘显示。

- **用户列表**：按用户名、昵称、备注搜索；按正常/停用筛选；分页；编辑显示名称、状态、并发上限、单任务账号上限、CDK 融合权限和管理员备注。
- **用户策略**：动态设置是否开放注册、最大用户数、新用户默认并发、单任务最大账号数和默认融合权限。
- **卡密库存**：搜索卡密/备注，筛选正常、停用、过期、已融合，显示额度和绑定时间。
- **任务记录**：按任务 ID、卡密、通道和状态筛选，查看成功/失败数量及执行时间。
- **提链日志**：按日志级别和关键字筛选，并支持清理审计日志。

用户策略只影响新注册用户；存量用户通过用户列表单独调整。所有管理修改会写入审计日志。

## 本地运行

前端仍通过 `http://127.0.0.1:5173` 访问，API 为 `http://127.0.0.1:8010`。API 的 `.env` 使用内网 PostgreSQL、Redis 和 Kafka 配置；本轮改造不需要向远程服务器部署文件。
